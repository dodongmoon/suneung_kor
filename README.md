# 시의 주제

2027 KBS 수능특강·수능완성 손필기 PDF의 작가·제목·주제로 학습하는 정적 웹 앱입니다. 총 92편을 교재와 갈래별로 학습합니다.

| 교재 | 현대시 | 고전시가 |
| --- | ---: | ---: |
| 수능특강 | 36편 | 33편 |
| 수능완성 | 12편 | 11편 |

## 배포

GitHub Pages 주소: https://dodongmoon.github.io/suneung_kor/

`main` 브랜치에 변경 사항을 올리면 `.github/workflows/pages.yml`이 퀴즈 테스트를 실행하고 `dist` 폴더를 자동 배포합니다. 저장소 Settings → Pages → Source는 GitHub Actions로 설정합니다. 별도 서버, API 키, ChatGPT 로그인은 필요하지 않습니다.

## 실행

```sh
npm run dev
```

브라우저에서 http://localhost:4173 을 엽니다. 별도 패키지 설치 없이 Python 3와 Node.js로 실행·검증할 수 있습니다.

```sh
npm test
```

## 학습 방식

- 작가와 제목을 보고 주제를 고릅니다. 선지는 3개 또는 5개입니다.
- 수능특강·수능완성을 선택한 뒤 현대시·고전시가를 고릅니다. 네 분류의 문제·선지·학습 기록·오답 목록을 각각 분리하며 교재나 갈래를 바꿔도 풀던 문제를 유지합니다.
- 정답 외 선지는 같은 교재·갈래의 다른 작품 주제 중 중복 없이 무작위로 뽑습니다. 같은 주제를 가진 작품이 여럿이어도 선지는 중복되지 않습니다.
- 전체 반복은 해당 교재·갈래의 1번부터 마지막 번호까지 순서대로 출제하고 다시 1번부터 반복합니다. 선지의 구성과 위치는 계속 무작위입니다.
- 답을 고르면 정답과 출처가 나오며, 다음 문제로 넘어갑니다.
- 문제 박스 위의 **본문 보기**로 해당 작품의 본문과 필기 페이지만 크게 확인할 수 있습니다. PDF 도구막대나 왼쪽 미리보기 없이 페이지를 보여주며 여러 쪽은 세로로 이어집니다. 페이지를 누르면 확대·축소할 수 있습니다. 답변 전후 모두 열 수 있고, 닫으면 문제·선지·점수가 그대로 유지됩니다.
- 본문 이미지들은 버튼을 누를 때 생성하며 아래쪽 페이지는 지연 로딩합니다. 「성패관천운」은 1쪽, 「면앙정가」는 3쪽처럼 해당 작품의 페이지만 포함합니다. 1600px 너비의 WebP 150개를 사용하며 최초 퀴즈 화면에서는 이미지나 PDF를 다운로드하지 않습니다. 이미지 로딩 실패 시 해당 작품의 원본 PDF 링크를 제공합니다.
- **틀린 문제 모아보기**에서 현재 교재·갈래의 틀린 작품만 번호순으로 확인합니다. 작품을 펼치면 마지막에 고른 오답, 정답, 출처가 나오며 본문도 열 수 있습니다. 예전 기록은 선택했던 선지가 없으면 정답만 표시합니다. **오답만 풀기**는 이 목록을 번호순으로 출제하며 다시 맞히면 목록에서 제거합니다.
- **이전 문제**는 같은 학습 모드의 최근 300개 문제를 돌아볼 수 있습니다. 선지와 선택한 답을 그대로 유지하고, 이미 채점한 문제는 다시 집계하지 않습니다. 다음 문제로 돌아오면 풀지 않은 문제를 이어서 풉니다. 학습 모드를 바꾸면 이전 문제 이동 이력은 새로 시작하며 누적 점수와 오답은 유지합니다.
- 진행 상태와 선지 개수, 학습 기록은 브라우저 localStorage에 섹션별로 저장합니다. 기존 수능특강의 현대시·고전시가 기록과 저장 키를 유지하며 기기 간 동기화는 하지 않습니다. 초기화도 선택한 섹션에만 적용됩니다.
- 무작위 출제 방식의 이전 저장 데이터(v1)는 누적 점수·오답·선지 개수를 유지하고 전체 반복 1번부터 시작하는 v2로 자동 전환합니다. 이후에는 이전 문제 이동 이력과 풀던 문제도 함께 저장합니다.
- 숫자키 1~5로 선택할 수 있습니다. 답변 뒤 다음 문제 버튼은 Enter로 실행할 수 있습니다.
- 작품 모아보기에서 제목·시인·주제를 검색하고 주제를 펼쳐 확인할 수 있습니다.

## 자료

수능특강은 `dist/poems.js`(현대시)와 `dist/classical-poems.js`(고전시가), 수능완성은 `dist/suwan-poems.js`에 정리했습니다. 각 작품의 `sourceRange`와 `sourcePage`로 원본 PDF 묶음과 페이지를 추적할 수 있습니다. 제목 영역을 원본 화면과 대조했습니다. 작품별 PDF는 `dist/pdfs/works`, 화면에 표시하는 이미지는 `dist/pages`에 있으며 `dist/sources.js`와 `dist/page-images.js`에서 작품별 파일과 페이지 수·크기를 연결합니다. 분리한 150쪽을 원본 렌더링과 비교해 본문과 필기 보존을 검증한 뒤, WebP 품질 90으로 화면용 이미지를 만들었습니다. 자료 순서와 별개로 작품 번호순으로 정리하고, 주제 문구의 줄바꿈과 필기 강조 표시는 정리했습니다.

수능특강 고전시가 「면앙정가」에는 별도의 주제 문구가 없어 3주차 PDF 1–3쪽의 필기(자연의 경치 예찬, 풍류와 삶의 만족, 임금의 은혜에 대한 감사)를 요약했습니다. 해당 작품의 정답·작품 목록에 ‘필기 요약’으로 구분하여 표시합니다. 나머지 주제는 PDF 주제 문구를 옮겼습니다. 수능완성 4개 PDF의 23편은 모두 주제가 명시되어 있으며 제목·작가·주제를 원본 제목 영역과 대조했습니다. 수능완성의 여러 쪽 작품은 `sourceEndPage`로 끝 쪽까지 기록합니다.

화면은 `dist/index.html`, 디자인은 `dist/style.css`, 퀴즈 규칙은 `dist/engine.js`, 브라우저 상호작용은 `dist/app.js`에 있습니다.

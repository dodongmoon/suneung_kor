# 시의 주제

2027 KBS 수특 손필기 PDF의 작가·제목·주제로 학습하는 정적 웹 앱입니다. 현대시 36편(PDF 9개)과 고전시가 33편(PDF 7개)을 별도 섹션에서 학습합니다.

## 배포

GitHub Pages 주소: https://dodongmoon.github.io/suneung_kor/

`main` 브랜치에 변경 사항을 올리면 `.github/workflows/pages.yml`이 퀴즈 테스트를 실행하고 `dist` 폴더를 자동 배포합니다. 저장소 Settings → Pages → Source는 GitHub Actions로 설정합니다. 별도 서버, API 키, ChatGPT 로그인은 필요하지 않습니다.

## 실행

```sh
npm run dev
```

브라우저에서 http://localhost:4173 을 엽니다. 별도 패키지 설치 없이 Python 3와 Node.js로 실행·검증할 수 있습니다.

```sh
npm test
```

## 학습 방식

- 작가와 제목을 보고 주제를 고릅니다. 선지는 3개 또는 5개입니다.
- 현대시와 고전시가의 문제·선지·학습 기록·오답 목록을 각각 분리합니다. 섹션을 전환해도 각 섹션에서 풀던 문제를 유지합니다.
- 정답 외 선지는 같은 섹션의 다른 작품 주제 중 중복 없이 무작위로 뽑습니다. 같은 주제를 가진 작품이 여럿이어도 선지는 중복되지 않습니다.
- 전체 반복은 해당 섹션의 모든 작품을 무작위 순서로 한 번씩 출제하고 다시 섞습니다.
- 답을 고르면 정답과 출처가 나오며, 다음 문제로 넘어갑니다.
- 문제 박스 위의 **본문 보기**로 해당 작품의 손필기 PDF를 확인할 수 있습니다. 답변 전후 모두 열 수 있고, 닫으면 문제·선지·점수가 그대로 유지됩니다.
- PDF는 버튼을 누를 때만 불러오고 닫으면 뷰어를 제거합니다. 원본 화질의 PDF 16개(총 약 6.8 MB)를 사용하며 최초 퀴즈 화면에서는 다운로드하지 않습니다. 브라우저에서 PDF가 잘 보이지 않으면 **새 탭에서 열기**를 사용할 수 있습니다.
- 오답 복습은 틀린 작품을 모아서 출제하며 맞히면 목록에서 제거합니다.
- 진행 상태와 선지 개수, 학습 기록은 브라우저 localStorage에 섹션별로 저장합니다. 기존 현대시 기록을 유지하며 기기 간 동기화는 하지 않습니다. 초기화도 선택한 섹션에만 적용됩니다.
- 숫자키 1~5로 선택할 수 있습니다. 답변 뒤 다음 문제 버튼은 Enter로 실행할 수 있습니다.
- 작품 모아보기에서 제목·시인·주제를 검색하고 주제를 펼쳐 확인할 수 있습니다.

## 자료

`dist/poems.js`(현대시)와 `dist/classical-poems.js`(고전시가)의 `sourceRange`와 `sourcePage`로 원본 PDF 묶음과 페이지를 추적할 수 있습니다. 제목 영역을 원본 화면과 대조했습니다. 원본 PDF는 `dist/pdfs`에 있으며 `dist/sources.js`에서 작품별 파일과 시작 쪽을 연결합니다. 브라우저의 PDF 뷰어에 따라 `#page` 이동을 지원하지 않을 수 있어 화면에 쪽 번호도 표시합니다. 자료 순서와 별개로 작품 번호순으로 정리하고, 주제 문구의 줄바꿈과 필기 강조 표시는 정리했습니다.

고전시가 「면앙정가」에는 별도의 주제 문구가 없어 3주차 PDF 1–3쪽의 필기(자연의 경치 예찬, 풍류와 삶의 만족, 임금의 은혜에 대한 감사)를 요약했습니다. 해당 작품의 정답·작품 목록에 ‘필기 요약’으로 구분하여 표시합니다. 나머지 주제는 PDF 주제 문구를 옮겼습니다.

화면은 `dist/index.html`, 디자인은 `dist/style.css`, 퀴즈 규칙은 `dist/engine.js`, 브라우저 상호작용은 `dist/app.js`에 있습니다.
